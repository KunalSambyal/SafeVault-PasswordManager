# SafeVault

SafeVault is an ultra-secure, zero-knowledge, offline-first password manager engineered for Android using React Native, Expo (TypeScript), and SQLite.

The application ensures complete privacy by isolating sensitive credentials on-device, protected by hardware-backed encryption, with zero network communication capabilities.
